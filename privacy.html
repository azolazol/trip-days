개인정보 처리 안내

적용일: 2026년 10월 17일 · 운영자: azolpharm

이 안내는 Trip Days의 오사카·후쿠오카·시드니 및 앞으로 추가되는 모든 여행지에 공통 적용됩니다. 새로운 기능에서 수집 항목이 달라지면 이용 전에 안내합니다.

1. 어떤 정보를 처리하나요?

기능·목적처리 항목보관·삭제
문의 접수·답변·오류 확인유형, 내용, 도시, 접수번호·시각, 브라우저 식별값의 해시. 답변 이메일은 선택접수 후 최대 90일. 목적 달성 또는 정당한 삭제 요청 시 먼저 삭제. 자동삭제 설정이 확인된 경우에만 접수
선택 방문통계통계 전용 무작위 식별값의 해시, 최초·최근 방문일개별 방문기록은 최근 방문 후 최대 90일. 동의 선택·통계 토큰은 브라우저에 최대 90일. 철회 시 삭제 요청
내 장소 저장·수정브라우저별 무작위 소유권 토큰, 도시, 장소 이름·주소·메모·지도 링크·생성 및 수정 시각직접 삭제하거나 서비스 종료 시까지. 내 장소의 삭제 버튼으로 서버 기록 삭제
공개 추천사용자가 추천한 장소 이름·주소·메모·지도 링크추천 철회 또는 원본 삭제 시 공개 목록에서 삭제
여행 일정·화면 복원숙소 입력, 여행 설정, 선택 장소, 일정, 장소 캐시이용자의 브라우저 저장소에 보관. 사이트 데이터 삭제 시 제거

브라우저 식별값을 이름·이메일과 연결해 광고 프로필로 사용하지 않습니다. 해시값도 다른 정보와 결합될 수 있으므로 ‘완전한 익명정보’라고 표현하지 않습니다. 약국의 환자·처방정보를 이 서비스로 가져오지 않습니다.

2. 동의와 선택권

문의 처리 동의를 거부하면 문의 접수는 제한되지만 여행 기능은 계속 사용할 수 있습니다. 답변 이메일 제공은 선택이며, 제공하지 않아도 문의를 접수할 수 있지만 이메일 답변은 받을 수 없습니다. 이메일을 제공하려면 별도의 선택 동의가 필요합니다.

방문통계는 기본적으로 꺼져 있으며, ‘개인정보·방문통계 설정’에서 허용·거부·철회할 수 있습니다. 거부해도 일정 생성·저장은 이용할 수 있습니다. 거부 후 수치가 표시되지 않는 것은 오류가 아닙니다. 철회 전 집계된 전체 수치를 소급해 사람 수와 정확히 대응시키지는 않습니다.

3. 외부 서비스와 광고

현재 배포 코드에는 Google Analytics·광고 SDK가 없습니다. 향후 광고나 외부 분석 도구를 도입할 때 제공업체, 수집정보, 처리 목적, 보관기간, 국외이전 해당 여부 및 필요한 동의를 먼저 정비합니다. 통계 허용을 미래 광고 동의로 사용하지 않습니다.

  • GitHub Pages: 웹사이트 파일을 제공합니다. GitHub는 사이트 보안 목적으로 방문자의 IP 주소를 기록할 수 있습니다. 이는 Trip Days 선택 통계와 별개입니다. GitHub 개인정보 안내
  • Google Apps Script·Sheets: 여행지 목록 제공, 내 장소·추천 저장, 준비가 완료된 문의·통계 기능의 비공개 저장에 사용합니다. 서비스 요청 과정에서 Google이 접속정보를 처리할 수 있습니다. Google 개인정보 안내
  • Google Maps: ‘Google 지도 불러오기’를 누르면 Google에 접속정보와 선택한 장소·숙소 검색어가 전달됩니다. 화면 내 지도는 클릭 전 연결하지 않습니다. 외부 지도 링크를 직접 열면 해당 서비스의 정책이 적용됩니다.

외부 서비스 제공자의 로그·백업·처리 위치는 해당 서비스 정책과 계약에 따르며, 운영자가 모든 저장 위치나 즉시 삭제를 통제한다고 보장하지 않습니다. 문의 접수는 운영자의 제공업체·처리위탁·국외이전 사항 확인이 완료된 뒤 활성화됩니다.

4. 삭제·열람·정정 요청

문의하기 아래 ‘이 브라우저로 접수한 문의 삭제’로 해당 브라우저의 접수 건을 삭제할 수 있습니다. 다른 브라우저에서 접수했거나 열람·정정이 필요하면 문의 유형에서 ‘개인정보 열람·삭제 요청’을 선택하고 접수번호를 알려주세요. 필요한 범위에서 본인 여부를 확인합니다.

내 장소의 ‘삭제’는 관련 공개 추천도 삭제합니다. ‘내 추천 철회’는 공개 추천만 내리며 내 장소는 유지합니다. 브라우저 데이터를 지우기 전에 서버의 내 장소와 문의를 먼저 삭제하세요. 브라우저 저장소만 지우면 서버 기록은 지워지지 않고 소유권 토큰을 잃을 수 있습니다.

전자적 정보는 운영 중인 저장소에서 행·기록을 삭제하는 방식으로 파기합니다. 서비스 제공자의 백업·버전 이력은 해당 제공자의 보관·삭제 절차를 따릅니다. 법령상 보존이 필요한 경우 해당 근거·기간에 따라 분리 보관합니다.

5. 안전한 운영

운영 저장소는 공개 공유하지 않고 운영자 접근으로 제한합니다. 문의 알림 메일에는 새 문의가 있다는 사실만 담고 본문·답변 이메일을 복사하지 않습니다. 비밀번호, 결제정보, 건강정보와 타인의 개인정보를 문의·메모에 입력하지 마세요. 공개 추천에는 개인 숙소 주소 등 공개를 원하지 않는 정보를 넣지 마세요.

이 안내가 변경되면 변경일과 내용을 표시합니다. 수집 목적·항목이 확대되는 경우 필요한 별도 동의를 받습니다.
